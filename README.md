# 工业余热回收 · 智能决策演示平台（纯前端 v3）

面向《工业废热/余热回收利用降碳技术路径与智能优化评价方法》的交互演示平台。

- **决策内核 v2.1**：12 条技术路径（发电/工艺蒸汽/供暖/供冷/干燥/储热…）、
  驱动来源区分、边界工况提示、650℃ 能力圈外提示；纯 JS 实现，
  与 Python 权威内核对拍 0 差异（11 场景）。
- **实时数据接入**：统一遥测帧协议 + 四种数据源（模拟 / 历史 CSV 回放 /
  HTTP 轮询 / WebSocket 推送），为将来接入工厂实时数据预留接口
  （详见 `README_数据接入接口.md`）。
- **使用**：直接打开 `index.html`（单文件、离线可用），或访问本 Pages 地址；
  也可用 `启动_HTTP演示.bat` 起本地 HTTP 数据源演示。

> 数据口径：本平台为竞赛演示。CoolProp 物性仿真、代理模型、TOPSIS 指标
> 与成本均采用演示/文献口径；公开案例仅用于方法回溯。正式工程应用须以
> 现场实测与完整校核为准。
